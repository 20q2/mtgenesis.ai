# AI Night Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add username login, 3-card commander sets with rerolls and lock-in, per-set voting with host-run events, queue visibility, and much better card art to MTGenesis.AI.

**Architecture:**
- **Storage:** SQLite and PNG files under `proxy-server/data/`.
- **Generation:** a two-stage in-process queue, with one text worker and one image worker.
- **Routes:** new routes live in a Flask Blueprint that receives its dependencies as arguments, so modules are testable without importing the heavy `app.py`.
- **Frontend:** Angular 16 moves to routed pages that submit jobs and poll them.

**Tech Stack:** Python 3.12, Flask 3, stdlib `sqlite3`, pytest, diffusers (SDXL, `Lykon/dreamshaper-xl-lightning`), torch 2.8 cu128, Ollama `mistral:latest`, Angular 16 + Angular Material, Karma/Jasmine.

**Spec:** `docs/superpowers/specs/2026-09-28-ai-night-design.md`. Read it before any task. It holds the rules this plan references by section (§).

## Review Focus

1. **Double submits and racing votes.** A double-click on Vote, or two tabs voting at the same moment, must leave exactly one vote row and never return a 500. Tested in A3 by `test_concurrent_votes_single_row`.
2. **Stale login after a data reset.** If `proxy-server/data` is wiped between nights, a browser still holding an old user id must be sent back to `/login` with the stored user cleared, not left on a page full of failed requests. Tested in D1 by the `authInterceptor` 401 spec.
3. **Ollama or GPU down.** A card whose text or art function throws must end up `failed` with a readable error, and its slot must be rerollable. It must never stay `generating` forever. Tested in B2 by `test_text_failure_marks_failed`.
4. **Odd commander names.** A 41-character name, a blank name or a name of spaces returns 400. A name with an apostrophe or accents, such as "Zur'ka, Élan of Ash", is accepted and used unchanged as the card name. Tested in A2 by `test_commander_name_validation`.
5. **Rerolling a card still in progress, and media path traversal.**
   - A reroll on a card that is `queued`, `generating` or `rendering` returns 409 and must not queue a duplicate.
   - `/media/...` with a non-UUID id returns 404.

   Tested in A2 by `test_reroll_rejects_in_progress` and in A4 by `test_media_rejects_bad_id`.

    def get_card(self, card_id: str) -> dict | None: ...
    def update_card(self, card_id: str, **fields) -> None: ...   # accepts status,text_ready,art_ready,card(dict),art_path,card_path,error,finished_at
    def list_user_cards(self, user_id: str) -> list[dict]: ...   # newest first, replaced included
    def count_pending(self, user_id: str) -> int: ...            # status in queued|generating|rendering
    def unfinished_card_ids(self) -> list[str]: ...              # same statuses, all users
    # sets (rows: id,user_id,event_id,commander_name,prompt,card_params,status,created_at,locked_at)
    def create_set(self, user_id: str, commander_name: str, prompt: str, card_params: dict) -> dict: ...  # abandons existing draft

    def unlock_set(self, set_id: str, user_id: str) -> dict: ...

    def close_event(self, event_id: str) -> dict: ...
    def current_event(self) -> dict | None: ...
    def get_event(self, event_id: str) -> dict | None: ...
    def list_events(self) -> list[dict]: ...                     # newest first
    def locked_sets(self, event_id: str) -> list[dict]: ...      # oldest lock first
    # votes
    def cast_vote(self, voter_id: str, set_id: str, card_id: str) -> None: ...
    def vote_tally(self, set_id: str) -> dict[str, int]: ...     # card_id -> count (only cards with votes)
    def user_vote(self, voter_id: str, set_id: str) -> str | None: ...

### TypeScript: `src/app/models/api.model.ts` (additions)

```ts
export type CardStatus = 'queued' | 'generating' | 'rendering' | 'done' | 'failed';
export interface User { id: string; username: string; }
export interface CardParams { name: string; manaCost: string; supertype?: string; colors: string[]; type: string;
  subtype?: string; rarity: string; cmc: number; description?: string; power?: string; toughness?: string; }
export interface GeneratedCardData extends CardParams { flavorText?: string; }
export interface CardView { id: string; userId: string; setId: string | null; slot: number | null; replaced: boolean;
  status: CardStatus; error: string | null; textReady: boolean; artReady: boolean;
  queuePosition: number | null; etaSeconds: number | null; card: GeneratedCardData | null;
  cardImageUrl: string | null; artImageUrl: string | null; createdAt: string; }
export interface SetCardView extends CardView { votes: number; leader: boolean; tied: boolean; }
export interface SetView { id: string; userId: string; username: string; eventId: string | null; commanderName: string;
  prompt: string; status: 'draft' | 'locked' | 'abandoned'; lockedAt: string | null; cards: SetCardView[];
  myVoteCardId: string | null; }
export interface EventSummary { id: string; name: string; status: 'open' | 'closed'; createdAt: string; closedAt: string | null; }
export interface EventView extends EventSummary { sets: SetView[]; }
export interface QueueStatus { busy: boolean; cardsAhead: number; generatingNow: number; avgImageSeconds: number; etaSeconds: number; }
export interface GenerationRequest { prompt: string; cardData: CardParams; count: 1 | 3; commanderName?: string; }
export interface GenerationResponse { setId: string | null; cards: CardView[]; }
```

**Position semantics:**
- `queuePosition` is the 1-based index in the image wait list, or `0` while the card's art is being painted. It is `null` once `artReady` is true or the card is finished or failed.
- `etaSeconds` = (remaining time on the image currently painting) + `avg × queuePosition`.
- `avg` is the mean of the last 10 image durations, or `default_image_seconds` when there's no history.
- The remaining time on the current image is `max(avg − elapsed, 0)`, or 0 when nothing is painting.
- `status().etaSeconds` is the ETA a newly submitted card would get.
